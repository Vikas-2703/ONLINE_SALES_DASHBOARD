# 🛍️ Online Sales Dashboard

[![R Shiny](https://img.shields.io/badge/R-Shiny-blue)](https://shiny.rstudio.com/) [![Live App](https://img.shields.io/badge/View-App-green)](https://vikas-3967625.shinyapps.io/Assignment3-Vikas/)

An interactive R Shiny dashboard analyzing the [Kaggle Online Sales Dataset](https://www.kaggle.com/datasets/shreyanshverma27/online-sales-dataset-popular-marketplace-data).

### ✨ Features
- Multi-tab dashboard: Overview, Sales Analysis, Revenue Comparison by Region
- Dynamic filters on Product Category and Region
- Summary KPIs: Total Revenue, Units Sold, Transactions, Average Order Value
- Visualizations: Bar charts, line plots, heatmaps (`ggplot2`, `plotly`)
- Deployed live on Shinyapps.io

### 💻 Tech Stack
- R, Shiny, dplyr, ggplot2, plotly, shinydashboard, DT
